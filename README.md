Snipe-and-Scale — a paper-trading bot for pump.fun bonding curves, replayed on 24 hours of real trades. It buys only fresh launches that pass a rug filter (creator has not sold, small dev buy, a handful of distinct buyers, real SOL in the curve), pyramids once into strength, and exits whole on take-profit, stop-loss, a trailing stop, or the creator selling. A drawdown guard stops new entries once equity is 20% below its peak.

## Run it

```sh
PYTHONHASHSEED=0 python3 -P -s main.py
```
